# 📊 Blinkit Sales Performance Analysis

## 📌 Project Overview  
This project analyzes Blinkit’s sales performance, customer satisfaction, and inventory distribution using SQL and Power BI to identify patterns across products, outlets, and locations.

---

## 🎯 Project Goal  
The goal is to extract meaningful business insights that support revenue optimization, improved customer understanding, and better outlet-level decision-making.

---

## 🧮 Key Business Metrics (KPIs)  
- Total Sales → Overall revenue generated  
- Average Sales → Revenue per transaction  
- Number of Items Sold → Volume of products sold  
- Average Rating → Customer satisfaction indicator  

---

## 📊 Analytical Scope (Business Questions Answered)  
- Impact of Fat Content on Sales Performance  
- Sales Distribution by Item Type  
- Outlet Performance based on Fat Content  
- Effect of Outlet Establishment Type on Sales  
- Sales Variation by Outlet Size  
- Geographic Sales Distribution across Locations  
- Comparative KPI Analysis across Outlet Types  

---

## 🛠️ Technologies Used  
- SQL  
- Power BI
